# v0.4 zero-phase実動画検証

同一Raw Pose、同一撮影面区間、同一IC/TO・歩行周期、同一角度定義を使い、v0.3.1のSavitzky–Golay処理とv0.4.0のlandmark-first処理を比較した。値は有効周期を歩行周期1% binへ集約したmedian representative cycle。正常参考波形は評価基準に使用していない。

## 採用処理

- 実fps: 59.9696 fps
- 低confidence閾値: `min(visibility, presence) < 0.5`
- 外れ値: 速度のmedian/MADから閾値を作り、逆方向へ戻る1〜2フレームの短いexcursionだけを除外
- 補間: 有効点に挟まれた100ms以下の欠損だけ
- filter: 4次Butterworth low-pass、6Hz、forward-backward zero-phase
- 代表波形: 関節別の品質不良周期を除外後、1% binごとのmedian

4Hzは変動抑制が大きい一方で左膝peakが6%歩行周期ずれ、右股関節最大値が2.005°低下した。8Hzは値・peak保持が良い一方、複数部位でframe-to-frame variationが増えた。6Hzは最大値差が-1.152〜+0.433°、ROM差が-1.017〜+0.386°、peak差が-1〜+3%歩行周期に収まり、中央値変動が全6波形で1.7〜8.2%減少したため採用した。

全985フレームの33点処理で、低confidence 1,756 landmark sampleを通常値から除外し、112 sampleを短い反転jumpとして除外、うち100 sampleを短時間補間した。股・膝は測定品質「高」、足は足部segment方向不安定のため「解析困難」。5周期が有効、除外周期は各関節0だった。

代表frameでは股の体幹―大腿、膝の大腿―下腿、足の下腿―heel―foot indexの点配置と算出角度を目視照合した。右膝72.6°のframeは動画上でも明確な遊脚期屈曲だった。足部は計算点とは整合したが追跡方向が不安定であり、滑らかな値として採用せず解析困難表示を維持した。
