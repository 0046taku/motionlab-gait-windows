# 解析定義と制約

解析バージョン: `motionlab-gait-windows/0.4.0`

## Quality

Qualityスコアは、33点検出率25%、全点平均visibility 15%、下肢10点visibility 20%、時系列連続性10%、急な位置飛びの少なさ5%、矢状面適合度25%の重み付き合計です。Aは85以上、Bは70以上、Cは50以上、Dは50未満です。撮影面が混在した場合は最大B、3秒以上の矢状面区間がなければDとします。これは撮影・Poseの内部品質指標であり、臨床妥当性スコアではありません。

## 撮影面と解析区間

左右の肩・股関節の画像上の幅を体幹長で正規化し、MediaPipeの左右肩z差も補助的に使って、各フレームの矢状面適合度を算出します。0.5秒の移動中央値で安定化し、3秒以上続く最長の矢状面区間だけを定量解析します。前額面・斜め・旋回区間はPoseと動画には残しますが、IC/TO、周期、時間指標、角度から除外します。

これは撮影面を推定する保守的な内部ルールです。正確なカメラ外部標定ではないため、画面の警告と元動画を確認してください。

## ランドマーク処理

- `visibility`と`presence`の小さい点は加工計算から除外する。既定閾値は0.5。
- 正規化座標の速度をMADで評価し、大きな速度変化の直後に逆方向へ戻る1〜2フレームだけを単発landmark jump候補にする。持続する同方向の高速運動は除外しない。
- 両端に有効値がある100ms以下の欠損だけを線形補間する。長い欠損は埋めない。
- 動画の実fpsを使い、有限な連続区間へ4次Butterworth low-pass（6Hz）をforward-backwardで適用する。位相遅れを生じないzero-phase処理で、短すぎる区間は平滑化しない。
- 生Pose JSONLは変更しない。processed JSONLへ`interpolated`と`outlier_replaced`を保存する。

処理順序は、Raw landmark → 低confidence除外 → 短い反転jump除外 → 短時間欠損補間 → landmark filter → 関節角度 → 歩行周期正規化です。角度算出後だけを平滑化する処理はしません。同じ加工済みlandmarkの経路を股・膝・足関節で共通使用し、角度定義だけを関節別に保ちます。

4/6/8Hzを同じ実動画で比較し、4Hzは左膝peak timingが6%歩行周期ずれ、8Hzは変動低減が小さい部位があったため、peak・ROM保持とjitter低減の折衷として6Hzを採用しました。正常波形へのcurve fittingは行いません。各周期は関節別のcoverage、confidence、補間率、外れ値率で除外し、通常グラフは有効周期を1%刻みへ正規化したmedian cycleです。Research ModeではRaw角度とFiltered角度を重ね、peak、ROM、peak timing、frame-to-frame variationを確認できます。

## 進行方向・IC・TO

骨盤中心の動画前半/後半の水平変位から左右方向を推定します。変位が小さい、折返し、トレッドミルでは`unknown`になります。

自動イベントは、進行方向を揃えた同側股関節に対する踵・足趾の水平軌跡の極値、最小イベント間隔、同側IC間の時間範囲、IC–TO–次ICの時間制約を組み合わせた候補です。同側ICから次の同側ICを1周期とします。各イベントには信号突出度、ランドマーク信頼度、方向信頼度から0〜1の内部confidenceを付けます。

これは側方単眼動画用の研究アルゴリズムです。足マーカーを使う従来法とも同一ではなく、床反力計に対する検証は未実施です。病的歩行や足部遮蔽では必ず動画上で確認し、必要なら手動修正してください。

## 時間指標

- step time: 左右交互のIC間隔
- stride time: 同側ICから次の同側IC
- stance time: ICから同側TO
- swing time: TOから次の同側IC
- stance/swing %: TOが存在する同一周期ごとに算出して平均する（両者の合計は100%）
- cadence: 60÷平均step time
- symmetry index: `100 × |L − R| / ((L + R) / 2)`。0%が左右同等
- walking speed: ユーザーが既知距離と開始/終了時刻を入力した場合だけ、距離÷時間で算出

ピクセル距離から歩幅・歩行速度を推定しません。既知距離がない場合は`算出不可`です。

## 2D関節角度

進行方向を正に揃え、画像y軸を上向きへ変換した矢状面投影角度です。

- 股関節: 体幹下向き軸と大腿軸の符号付き角。前方屈曲を正。
- 膝関節: `180° − hip-knee-ankle内角`。屈曲を正。
- 足関節: 下腿軸と`heel-to-foot_index`足部軸のなす角を90°基準へ変換する。背屈を正。靴・遮蔽・足部点の影響が大きいためconfidenceを低くする。

各関節はvisibility、presence、外れ値率、補間率、tracking continuity、角度の単発jump率、有効周期数から`高 / 注意 / 解析困難`を判定します。足関節は踵―足趾segmentの方向安定性も確認し、品質不十分時に滑らかな波形を補作しません。

カメラが完全な側方でない場合、骨盤回旋・体幹傾斜・遠近変形が混在します。三次元関節角度ではありません。

## 成人参考帯

グラフの参考波形は初期OFFです。任意で成人・平地・快適歩行における一般的な矢状面パターンを重ねられます。概略範囲は股関節約-10〜35°、膝約5〜60°、足関節約-15〜15°です。単一施設の厳密な正常データではなく、2D MediaPipeの定義と3D motion captureの定義も一致しないため、正常/異常判定には使用しません。年齢、速度、疾患、装具、計測モデルを揃えた基準データは将来別途検証します。

参考: Michelini et al., 2020, PMID 32507049; Stenum et al., 2021, PMID 33891585。

## 観察特徴

閾値を超えた測定上の左右差だけを文章化します。原因は断定しません。「確認候補」は追加の臨床評価項目で、測定結果とは画面上で分離します。閾値自体も未検証であり、今後データセットで調整・固定する必要があります。
